# 不初限时狂欢商城

一套**零依赖、免登录**的单文件商城，专为本活动 3 天清仓设计。活动结束即弃用，无需维护。

---

## 一、怎么跑起来

1. 电脑上已自带 Node.js，无需另外安装。
2. 双击桌面 **`不初限时狂欢商城.lnk`** —— 会自动无黑框启动商城服务，并打开买家首页。
   - 或手动：在该文件夹按住 Shift 右键「在此处打开终端」，输入 `node server.js`。
3. 默认端口 4100。

> ⚠️ 启动后任务栏会有一个小黑框（Node 服务），那是正常的。商城在运行时不要关掉它，关了商城就停了。

### 各页面地址（本机打开）
| 页面 | 地址 | 用途 |
|------|------|------|
| 买家首页 | `http://localhost:4100/` | 客户看到的商品墙 |
| 单品页 | `http://localhost:4100/product/<商品ID>` | 单个商品详情（分享到微信是大卡片） |
| 订单页 | `http://localhost:4100/order/<订单号>` | 客户查单 / 看物流 |
| 商家后台 | `http://localhost:4100/admin` | 你用来收单、确认、发货 |

## 二、怎么改成你自己的商品

编辑 **`data/products.json`**（用记事本打开即可）：

```json
{
  "id": "blind-299",          // 唯一ID，别重复，单品链接用它
  "name": "告别盲盒 · 299档",
  "price": 299,               // 售价
  "originalPrice": 1000,      // 划线原价（不填或≤售价则不显示）
  "image": "/assets/products/blind-299.svg",  // 图片路径
  "desc": "价值1000+，保底1样主打品",
  "stock": 100,               // 库存（仅展示，不影响下单）
  "category": "盲盒"
}
```

**换真实产品图**：把图片（jpg/png）放进 `public/assets/products/` 文件夹，把上面 `image` 改成 `/assets/products/你的图.jpg`。

加商品就照着往数组里加一项；删商品就删掉一项。保存后**重启** `node server.js`（关终端重开）。

## 三、店铺名 / 联系人 / 收款码 / 公告

两种方式，任选：

- **后台改（推荐）**：打开 `/admin` → 点「⚙️ 店铺设置」→ 填店铺名、联系人（默认“夏天老师”）、公告，上传微信/支付宝收款码图片 → 保存。
- **手动改**：编辑 `data/config.json`。

> 收款码建议用**个人收款码**（微信/支付宝里「收付款 → 二维码收款 → 保存图片」），客户扫码直接转账给你，不经平台、无手续费、也无微信留痕。

## 四、完整流程（客户视角）

1. 你把首页或单品链接发微信群 / 朋友圈。
2. 客户点开 → 加购多件 → 去结算 → 填姓名电话地址 → 提交订单。
3. 跳转订单页 → **扫码支付** → **截图付款金额发给夏天老师核对**。
4. 你后台看到「待付款」订单 → 确认收到款 → 点「我已确认收款」→ 变「待发货」。
5. 你打包 → 点「填写单号发货」填快递单号 → 变「已发货」。
6. 客户刷新自己的订单页 → 看到快递单号。

后台每 15 秒自动刷新，不用手动点。

## 五、微信里显示“大卡片”

链接分享到微信时显示的卡片（标题+图+描述）由页面的 Open Graph 信息决定，已自动配好：

- 首页卡片 = 店铺名 + 公告 + 分享图
- 单品卡片 = 该商品名 + 描述 + 商品图

**前提**：页面必须部署到**公网**（见下），微信才能抓到卡片。本机 `localhost` 在微信里打不开、也抓不到卡片。

---

## 六、怎么让 3000 个客户都能打开（部署到公网）

本机 `localhost` 只有你自己的电脑能开。要客户访问，必须把这套传到一台**有公网 IP 的服务器**上跑。最简单三选一：

1. **Render（免费）**：把 `clearance-shop` 文件夹当 Node 项目传上去，Start Command 填 `node server.js`，免费额度够 3 天活动。
2. **Fly.io / Railway**：类似，都有免费档。
3. **自己的云服务器（阿里云/腾讯云轻量）**：把文件夹传上去 `node server.js`，用 Nginx 反代 4100 端口并绑域名。

部署后把域名发客户即可。需要我帮你出某家的详细步骤，说一声。

## 七、数据安全（重点：不会丢单）

- 订单存在 `data/orders.json`。
- 写入采用**原子写（先写临时文件再替换）+ 串行锁**，避免“写到一半崩了文件损坏”的老问题。
- 每次保存前自动备份到 `data/orders.json.backup`，真出意外也能恢复。
- 活动期间**别手动删 `data/` 文件夹**，也别在运行时去改 `orders.json`。
