# 不初限时狂欢商城 · 云部署指南

> ⚠️ 前置结论：**微信分享卡片（大图）必须在公网才能生效**。`localhost` 只有你本机能开，
> 微信根本访问不到，也拉不到分享图。所以上线 = 把商城部署到一个公网网址。

---

## 一、准备（一次性）

1. 在 GitHub / Gitee 新建一个仓库，把整个 `clearance-shop/` 目录推上去
   （已内置 `package.json` / `Dockerfile` / `deploy/` 配置，开箱即用）。
2. 注册一个云平台账号（下面二选一，都免费够用）：
   - **Fly.io**（全球节点，国内打开稍慢但稳）→ https://fly.io
   - **Render**（美国节点，免费档会休眠）→ https://render.com

---

## 二、用 Render 上线（最简单，网页点几下）

1. 登录 Render → New → Web Service → 关联你的仓库。
2. 设置：
   - Runtime: **Docker**
   - 其余按仓库里的 `deploy/render.yaml` 自动识别（或手动：Start Command 留空，用 Dockerfile）。
3. 点 Create → 等 1~2 分钟构建完，得到形如 `https://laozhai-mall.onrender.com` 的网址。
4. 把这个网址发微信里发给客户，链接就会显示成**带大图的卡片**。

> Render 免费档空闲后会“休眠”，第一次打开要等几秒唤醒。介意的话用 Fly.io 或付费档。

---

## 三、用 Fly.io 上线（更快、全球稳）

1. 安装 flyctl：https://fly.io/docs/hands-on/installing/
2. 在 `clearance-shop/` 目录执行：
   ```bash
   flyctl launch   # 按提示选 region（建议 sin 新加坡 / hkg 香港）
   flyctl deploy
   ```
3. 部署完会得到 `https://laozhai-mall.fly.dev`（或你自定义的域名）。

---

## 四、绑定自己的域名（可选，更专业）

两个平台都支持绑自定义域名（如 `mall.你的品牌.com`），在平台控制台加一条 CNAME，
平台会自动签发 HTTPS 证书。绑好后把域名发微信，卡片更可信。

---

## 五、让微信卡片显示“更大图”的进阶项（可选）

当前已配置好 Open Graph 元信息（`og:title` / `og:description` / `og:image` / `og:url`），
微信**默认分享**就会显示成「标题 + 描述 + 缩略图」的卡片（不再是裸网址）。

若想要**图片占满顶部的大图卡片**（类似朋友圈那种），需要：
1. 你有一个**微信认证服务号**（订阅号不行）；
2. 在公众号后台配置“JS安全域名”= 你的商城域名，并上传校验文件；
3. 由我（阿布）再给商城加一段微信 JS-SDK 分享代码（需你的 AppID）。

这块等你上线域名 + 有服务号了，随时叫我加。

---

## 六、本地照常使用

部署不影响本地：双击桌面「不初限时狂欢商城」图标即可在 `http://localhost:4100` 打开，
数据都存在 `data/` 下，和线上是两套独立数据。
